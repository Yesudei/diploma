\section{Бүлгийн зорилго}
Энэ бүлэгт FL Studio болон хөгжим боловсруулалтын сургалтын платформын архитектур, өгөгдлийн бүтэц, хэрэглэгчийн урсгал, фронтенд хэрэгжилт, Supabase өгөгдлийн сан, RAG суурьтай AI туслах болон өгөгдлийн багц бэлтгэх дамжлагыг нэгтгэн тайлбарлана. Өмнөх бүлэгт сонгосон технологийн үндэслэлийг авч үзсэн бол энэ бүлэг нь тэдгээр сонголт бодит платформд хэрхэн хэрэгжсэнийг харуулна.

Платформын хэрэгжилт нь дараах үндсэн бүрэлдэхүүнтэй.
\begin{itemize}
  \item Next.js App Router дээр суурилсан веб аппликейшн;
  \item курсийн каталог, хичээлийн тоглуулагч, төлбөртэй хандалт, сорил, хяналтын самбар;
  \item Supabase Auth, PostgreSQL schema, Row Level Security бодлого;
  \item \texttt{/api/ai-chat} зам дээр ажиллах локал RAG суурьтай сургалтын туслах;
  \item Ollama, Qdrant, ingestion/generation script болон JSON/JSONL өгөгдлийн багц;
  \item локал хөгжүүлэлтийн буюу гэрийн компьютер дээр ажиллуулах тохиргоо.
\end{itemize}

\section{Хэрэглээний ерөнхий зураг}
Платформын үндсэн оролцогч нь зочин хэрэглэгч, бүртгэлтэй суралцагч, админ юм. Зочин хэрэглэгч курс хайх, үнэгүй танилцах хичээл үзэх, бүртгүүлэх боломжтой. Суралцагч курс худалдан авч, хичээл үзэж, сорил өгч, AI туслахаас асуулт асууж, ахицаа хадгална. Админ курс, хичээл, мэдлэгийн сан, хэрэглэгчийн мэдээллийг удирдана.

Зураг \ref{fig:ch1-usecase}-д хэрэглэгчийн үндсэн боломжуудыг харуулсан. AI туслах нь сургалтын үндсэн урсгалыг орлохгүй, харин хичээл үзэх явцад гарсан тодорхой асуултад context-тэй зөвлөгөө өгөх нэмэлт давхарга байдлаар байрлана.

\section{AI чатботын хэрэгжүүлэлт}
Сургалтын туслах нь \texttt{Frontend/src/app/api/ai-chat/route.ts} файлд байрлах Next.js route handler-ээр хэрэгжсэн. Энэ зам нь хэрэглэгчийн зурвасыг хүлээн авч, Монгол кирилл болон латин бичлэгтэй асуултыг normalization хийж, Ollama-ийн \texttt{bge-m3} embedding model-оор vector үүсгэн, локал Qdrant collection-оос хамгийн ойр контекстуудыг хайна. Дараа нь retrieved context дээр тулгуурласан prompt үүсгээд Ollama дээр ажиллаж буй \texttt{qwen3:8b} загвар руу \texttt{/api/chat} endpoint-оор сервер талын дуудлага илгээнэ. Хариулт буцахдаа \texttt{answer} болон эх сурвалжийн \texttt{title}, \texttt{category}, \texttt{score} талбаруудыг фронтенд рүү илгээдэг.

\begin{enumerate}
  \item UI-аас зурвас \texttt{/api/ai-chat} зам руу илгээгдэнэ.
  \item API зам request body-г шалгаж, хоосон эсвэл хэт урт зурвасыг буцаана.
  \item \texttt{normalizeMongolianQuery} функц латин Mongolian бичлэгийг хөгжмийн түлхүүр үгтэй баяжуулна.
  \item Ollama-ийн \texttt{/api/embed} endpoint дээр \texttt{bge-m3} model ашиглан embedding үүсгэнэ.
  \item Qdrant дээр cosine similarity ашиглан \texttt{music\_lessons\_rag} collection-оос top 5 chunk хайна.
  \item Retrieved chunk-уудыг Mongolian-focused prompt-д нэгтгэнэ.
  \item Ollama-ийн \texttt{/api/chat} endpoint дээр \texttt{qwen3:8b} model-оор хариу үүсгэнэ.
  \item Контекст хүрэлцэхгүй үед загвар таамаглахгүй, ``Энэ асуултад хангалттай мэдээлэл миний сургалтын сангаас олдсонгүй.'' гэж буцаана.
\end{enumerate}

\section{RAG өгөгдлийн багц}
Одоогийн RAG мэдлэгийн сан нь \texttt{Frontend/data/rag/music-course-seed.json} болон \texttt{Frontend/data/rag/generated-music-course.jsonl} файлуудаас бүрдэнэ. Seed файл нь DAW, FL Studio, BPM, beat structure, drum pattern, kick, snare, hi-hat, 808 bass, melody, chord, scale, EQ, compression, reverb, delay, mixing, mastering, arrangement, export зэрэг 20 үндсэн сэдвийг Монгол хэлээр агуулна. Generated JSONL файл нь Gemma/Ollama ашиглан үүсгэсэн 2000 нэмэлт beginner-friendly chunk-ийг хадгална. \texttt{npm run rag:ingest} script эдгээрийг embedding болгон Qdrant-д оруулна.

Цаашид Image-Line FL Studio manual зэрэг албан эх сурвалж \cite{flstudio_workflow} болон багшийн сонгож баталгаажуулсан сургалтын материал дээр тулгуурласан citation-safe бичлэг нэмэх шаардлагатай.

\section{Аюулгүй байдал ба өргөтгөх боломж}
Платформын аюулгүй байдал нь клиент хамгаалалт, серверийн зам, өгөгдлийн сангийн бодлого гэсэн гурван түвшинд хэрэгжинэ. Клиент талд төлбөртэй хичээлийн түгжээ болон админ холбоосын харагдах байдал хянагдана. Сервер талд Ollama/Qdrant холболт, retrieval, prompt бүрдүүлэх логик байрлана. Өгөгдлийн сангийн түвшинд RLS policy нь ахиц, худалдан авалт, чат зэрэг хэрэглэгч эзэмшдэг өгөгдлийг хамгаална.

\section{Бүлгийн дүгнэлт}
Гуравдугаар бүлгээр платформын архитектур ба хэрэгжилтийг нэгтгэн тайлбарлав. Платформ нь курсийн каталог, хичээлийн тоглуулагч, төлбөртэй хандалт, сорил, хяналтын самбар, админ хэсэг, AI чатбот гэсэн хэрэглэгчийн үндсэн урсгалтай бөгөөд Next.js, React, TypeScript, Supabase PostgreSQL, RAG өгөгдлийн багцын дамжлага дээр тулгуурласан. Use case, activity, layered, ER, AI sequence, deployment диаграмуудаар системийн үндсэн холбоо, өгөгдлийн бүтэц, AI туслахын хүсэлтийн урсгал, локал тохиргоог харууллаа.

AI туслахын хувьд \texttt{/api/ai-chat} зам нь query normalization, Ollama \texttt{bge-m3} embedding, Qdrant vector search, grounded prompt, Ollama \texttt{qwen3:8b} answer generation гэсэн дамжлагатайгаар хэрэгжсэн. Энэ нь дипломын MVP-д төлбөртэй API-гүй ажиллах бүтэц боловч production түвшинд хүргэхийн тулд citation-safe өгөгдлийн бичлэг нэмэх, retrieval evaluation хийх, payment integration болон admin CRUD-г бүрэн болгох шаардлагатай.
